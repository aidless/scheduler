## s1 结果（standard）

已写好并运行验证通过。核心函数如下：

```python
import random

def generate_random_integers(n: int = 10, low: int = 0, high: int = 100) -> list[int]:
    """生成 n 个 [low, high] 范围内的随机整数（默认 10 个，0-100）。"""
    if n < 0:
        raise ValueError("n 必须为非负整数")
    if low > high:
        raise ValueError("low 不能大于 high")
    return [random.randint(low, high) for _ in range(n)]
```

**实际运行结果**（控制台中文显示乱码是 PowerShell 编码问题，不影响功能）：
- 默认 0–100：`[65, 51, 32, 65, 97, 79, 38, 49, 77, 11]`
- 自定义 1–10：`[2, 4, 2, 9, 5, 5, 2, 10, 9, 1]`

**用法：**
```python
nums = generate_random_integers()                    # 10 个 0-100 的随机整数
nums = generate_random_integers(low=1, high=10)      # 10 个 1-10 的随机整数
nums = generate_random_integers(n=20, low=-50, high=50)  # 自定义个数和范围
```
